# Case File 5: The Annex

The dossier clue from Two Offices points to a small departmental
network Priya Okonkwo-Reyes calls "the Annex" — a gateway portal, a
directory service nobody outside IT ever thinks about, and a file
server that was never meant to be reachable from anywhere but inside
that same small network.

Her note says this is where her own access was traced to, the last time
anyone saw her logged in anywhere. She left an audit log on the file
server deliberately — not hidden, just behind everything else.

Her note: "I didn't get in through the front door. Neither should you."
